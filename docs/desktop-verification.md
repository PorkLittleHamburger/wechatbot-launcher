# 桌面验收指南

本页描述启动器仓库可重复执行的验证步骤。实际测试结果应随相应构建产物记录；不同软件版本、Windows 环境和微信构建需要分别验证。

## 自动化检查

### 0.8.10：真实 WebView2 窗口 smoke

Windows 上从仓库根目录执行（需构建工具链和前端资源）：

```powershell
cargo rustc --locked --manifest-path desktop/src-tauri/Cargo.toml --example instance_webview_smoke -- -C link-arg=/MANIFEST:EMBED -C "link-arg=/MANIFESTINPUT:$((Resolve-Path desktop/src-tauri/windows/debug.manifest).Path)"
```

以普通权限运行 Cargo 输出目录内的 `debug/examples/instance_webview_smoke.exe <绝对报告文件路径>`，等待退出并检查报告 `Ok(())`。该 opt-in 程序使用独立、每进程唯一应用标识，不启动管理服务或微信，不调用自启插件。它在随机本地 HTTP 端口提供测试页面，创建主窗口及两实例窗口，重复打开已有窗口，切换端口，再销毁并重建；测试浏览器数据保留在独立 smoke 标识目录。嵌入 Windows 清单是必需条件，否则独立 example 可能在入口加载阶段退出。

2026-11-12 本机真实 WebView2 smoke 通过，但旧代码同类 smoke 也通过，未精确重现用户的 `0x80010108`；不能代替目标安装上的最终复测。

卸载清理分别在 PowerShell 7 和系统 Windows PowerShell 下验证，只移除匹配安装路径的 Run 项及批准状态，保留其他安装和不自动恢复入口所需的迁移标记。构建同时验证轻量入口使用 Windows GUI 子系统和显式 `asInvoker` 清单。

自启路径回归使用含中文与空格的隔离文件，将 Tauri 返回的规范化 `\\?\` 资源路径转换为普通本地 Run 命令；旧命令迁移及回滚保留禁用标记的完整字节。卸载测试同时覆盖普通路径与旧前缀路径。实际机器诊断应结合 Shell-Core 登录事件与入口日志，不能只根据注册项和任务存在判断自启成功。

按 [构建说明](building.md) 配置外部运行时和 Python 环境后，在仓库根目录执行：

```powershell
$env:WECHAT_RUNTIME_SOURCE = (Resolve-Path ../wechatbot).Path
.venv/Scripts/python.exe -m pytest -q tests
pwsh -File scripts/build_desktop.ps1
```

完整构建包含启动器 Python 回归、外部运行时合并与校验、TypeScript 检查、前端生产构建和 Rust 测试。Rust 测试使用组装的 Python 运行时验证管理服务启动、请求响应及正常退出。

## 隔离安装验证

0.8.4 的路径交接回归覆盖：旧扩展盘符工作空间、中文及空格路径、生成配置的 helper/数据/媒体路径、Windows 实际目录身份、长路径保留、UNC/设备路径不变，以及尾点目录不被改写为另一个目录。测试只创建隔离目录并构造配置，不启动真实 helper 或访问微信。

旧配置中带扩展前缀的绝对数据/媒体路径也覆盖备份、恢复、归档与失败升级回滚；目录包含关系先解析链接再比较统一身份，I/O 保留原路径。备份操作断言原配置字节不变，恢复/回滚断言已有文件数据保留。

0.8.3 新增本体更新自动化检查：正式发布筛选、SHA-256 清单与安装前复验、下载失败/取消/总超时清理、缓存回收、元数据流量限额，以及安装助手成功/校验拒绝/安装失败恢复工作空间。助手测试替换 `Start-Process`，不实际启动安装器或 UAC；Rust 隔离运行时测试验证新工作空间版本列表为空、未准备安装器时拒绝交接。上述检查不替代真实覆盖安装验证。

在支持 Windows Sandbox 的主机上，构建安装器后运行：

```powershell
pwsh -File scripts/test_installer_sandbox.ps1
```

脚本生成 `dist/WeChat-OneBot-Offline-Acceptance.wsb`，默认只生成配置。配置关闭网络和剪贴板，安装器目录以只读方式映射，结果输出到 `dist/installer-acceptance`。打开生成的 `.wsb`，或添加 `-Launch` 参数启动。也可使用独立 Windows 虚拟机验收。

逐项确认：

1. 断网安装、选择目录、快捷方式和系统卸载入口正常；无需预装 Python 或开发工具。
2. 从快捷方式打开独立窗口，出现预期 UAC 提示，不显示控制台或打开外部浏览器。
3. 重复启动唤起原窗口，窗口尺寸和位置可恢复；关闭默认进入托盘，切换关闭行为后符合设置。
4. 托盘退出正常停止实例。测试专用进程异常结束后，所属管理服务和实例进程也结束，监听端口释放。
5. 在隔离环境创建两个专用测试实例，停止其中一个不影响另一个，核对独立子窗口。桌面固定创建 Helper 实例，不提供 Mock 入口；无微信的 Mock 生命周期验证使用 pytest 夹具完成，不能要求在界面选择 Mock。
6. 启用和关闭开机自启，实际注销并登录验证任务；检查隐藏启动和恢复实例设置，按已保存配置核对恢复结果与网关日志。
7. 程序运行时覆盖安装要求先正常退出，覆盖升级保留工作空间；卸载默认保留数据，明确选择删除时才清理。
8. 验证离线版本、下载失败重试、导入错误、升级回滚和备份恢复的界面提示及操作结果。

进程异常测试仅针对专门创建的验收实例。准备卸载数据删除测试前，应确认工作空间为专用测试空间。
